# Tableau Dashboard Spec

Source: `dashboard/tableau_extract.csv` (generated by
`python/export_for_tableau.py`). Connect Tableau directly to this
file and rebuild the workbook with the sheets below.

## Filters (global, applied to every sheet)
- `txn_date` (date range)
- `transaction_type` (multi-select)
- `device_used` (multi-select)
- `status` (Success / Failed)

## Sheets

1. **KPI tiles** — Total revenue, transaction volume, average
   transaction value, fraud-flagged count. Use `SUM(amount)`,
   `COUNTD(transaction_id)`, `AVG(amount)` as calculated fields,
   filtered to `status = Success` for revenue and volume.

2. **Revenue trend** — line chart, `txn_date` on columns,
   `SUM(amount)` on rows, colored by `transaction_type`.

3. **Contribution by type** — bar or pie chart, `transaction_type`
   on rows, `SUM(amount)` on columns, with percent-of-total label.

4. **Device performance** — bar chart, `device_used` on rows,
   `SUM(amount)` and `AVG(amount)` on columns.

5. **Failed-transaction rate** — bar chart, `transaction_type` on
   rows, `COUNTD(transaction_id) / {FIXED transaction_type :
   COUNTD(transaction_id)}` filtered to `status = Failed`.

6. **Anomaly review map** — map view using `latitude`/`longitude`,
   sized by `amount`, colored by `is_anomaly` (True = red), with a
   tooltip showing `transaction_id`, `amount`, `transaction_type`,
   `txn_timestamp`.

7. **Anomaly review table** — detail table, filtered to
   `is_anomaly = True`, columns: `transaction_id`,
   `sender_account_id`, `receiver_account_id`, `amount`,
   `transaction_type`, `txn_timestamp`, `device_used`,
   `network_slice_id`, sorted by anomaly rank.

## Layout
Dashboard 1 ("Sales Overview"): KPI tiles across the top, revenue
trend and contribution-by-type side by side below, device
performance at the bottom, all driven by the global filters.

Dashboard 2 ("Anomaly Review"): anomaly map on the left, anomaly
review table on the right, both filtered to `is_anomaly = True`.
