# Tableau Dashboard Spec

Source: `dashboard/tableau_extract.csv` (generated by
`python/export_for_tableau.py`). Connect Tableau directly to this
file and rebuild the workbook with the sheets below.

## Filters (global, applied to every sheet)
- `txn_minute` (range; the data covers 10:01 to 11:00 on one day)
- `transaction_type` (multi-select)
- `device_used` (multi-select)
- `status` (Success / Failed)

## Sheets

1. **KPI tiles**: total revenue, transaction volume, average
   transaction value, flagged-for-review count. Use `SUM(amount)`,
   `COUNTD(transaction_id)`, `AVG(amount)`, filtered to
   `status = Success` for revenue and volume, and
   `SUM(INT(is_anomaly))` for the flagged count.

2. **Revenue trend**: line chart, `txn_timestamp` on columns as an
   exact date truncated to the minute (or binned into 5 minutes),
   `SUM(amount)` on rows, colored by `transaction_type`.

3. **Contribution by type**: bar chart, `transaction_type` on rows,
   `SUM(amount)` on columns, with a percent-of-total label.

4. **Device performance**: bar chart, `device_used` on rows,
   `SUM(amount)` and `AVG(amount)` on columns.

5. **Failed-transaction rate**: bar chart, `transaction_type` on
   rows, calculated field
   `SUM(IIF([status] = "Failed", 1, 0)) / COUNT([transaction_id])`.

6. **Anomaly score distribution**: bar chart, `anomaly_score` on
   columns, `COUNT(transaction_id)` on rows, colored by `is_anomaly`.

7. **Anomaly review table**: detail table, filtered to
   `is_anomaly = True`, columns: `transaction_id`,
   `sender_account_id`, `receiver_account_id`, `amount`,
   `transaction_type`, `txn_timestamp`, `status`, `anomaly_score`,
   `anomaly_reasons`, sorted by `anomaly_score` descending then
   `amount` descending.

A map using `latitude`/`longitude` is possible but not recommended:
the source coordinates are random pairs of a few city values (see
`docs/workflow.md`), so the map would not show real geography.

## Layout
Dashboard 1 ("Sales Overview"): KPI tiles across the top, revenue
trend and contribution-by-type side by side below, device
performance and failed rate at the bottom, all driven by the global
filters.

Dashboard 2 ("Anomaly Review"): anomaly score distribution on the
left, anomaly review table on the right. Clicking a score bar
filters the table.
